PAINEL DE MOVIMENTOS DE VOOS - BABR
===================================

Arquivos: index.html, manifest.json, sw.js, icon-192.png, icon-512.png,
firebase-config.js, database.rules.json

TEMPO REAL: o arquivo firebase-config.js já está preenchido com o projeto
"Movimentos de voos - BABR". Falta apenas ligar o acesso anônimo (passo 3) e publicar (passo 5).
Sem o firebase-config.js preenchido o app funciona em "Modo local".

1) Criar o projeto
   - Entre em console.firebase.google.com e clique em "Adicionar projeto".

2) Criar o banco
   - Menu Build > Realtime Database > Criar banco de dados.
   - Escolha a região mais próxima e o modo bloqueado.
   - Aba "Regras": apague tudo, cole o conteúdo do arquivo database.rules.json e clique em Publicar.

3) Ligar o acesso anônimo
   - Menu Build > Authentication > Começar > aba "Sign-in method" > Anônimo > Ativar > Salvar.

4) Copiar os dados do app
   - Engrenagem > Configurações do projeto > "Seus apps" > ícone </> (Web) > Registrar app.
   - Copie apiKey, authDomain, projectId e appId.
   - O databaseURL aparece no topo da página do Realtime Database
     (exemplo: https://nome-do-projeto-default-rtdb.firebaseio.com).
   - Cole tudo no arquivo firebase-config.js.

5) Publicar
   - Suba todos os arquivos para o repositório do GitHub (substituindo os antigos).
   - O Render atualiza o site sozinho em cerca de 1 minuto.

6) Primeiro acesso (faça logo após publicar)
   - No app: Acesso > Administrador > informe seu nome e crie o PIN.
   - Quem criar primeiro define o PIN de administrador para todos.
   - Depois, em Acesso > Administrador, defina também o PIN do operador.

INSTALAR COMO APP
   - Android (Chrome): menu ⋮ > Instalar app.
   - iPhone (Safari): Compartilhar > Adicionar à Tela de Início.

LIMITES E CUIDADOS
   - O plano gratuito do Firebase permite até 100 pessoas conectadas ao mesmo tempo.
   - Os PINs controlam o que cada pessoa vê no app. Quem tiver conhecimento técnico
     consegue gravar no banco sem passar por eles. Para proteção forte, o próximo passo
     é login individual por e-mail.
